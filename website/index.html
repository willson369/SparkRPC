Netty · Custom Protocol · SPI

SparkRPC

为学习与小规模内部通信打造的高性能 RPC。自定义二进制协议、编解码与业务解耦，掌握网络编程核心路径。

打开项目 · GitHub 邮件沟通
2025

技术栈

Java 17 Netty 4 Custom Binary Protocol JSON / SPI JUnit 5 ZooKeeper（规划）

亮点

  • 自定义协议帧

    Length Field + Magic 校验，安全处理 TCP 粘包 / 半包。

  • 同步 Future 调用

    JDK 动态代理封装 RequestId 与超时，MVP 已支持同步等待。

  • 连接保活

    心跳与空闲检测，异常连接自动摘除，连接可复用。

  • SPI 可插拔

    序列化可扩展；注册中心适配预留（直连 MVP → ZK）。
